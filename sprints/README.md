# Sprints

Each assessment task has three sprints. Sprint 1 of Task 1 starts on Mon 12 Oct 2026. Each sprint ends with a Sprint Review, which the group submits on Blackboard by 14:01 on the due date (see the key dates in the [README](../README.md)). The next sprint starts on the day after the review.

The sprint goal and the high-level work items are in the Jira sprint. The tasks and their owners are in the GitHub project, in the same sprint. Each sprint also has a folder here, for example `task1-sprint1/`, with two files:

- `standups.md`: one entry for each weekly stand-up
- `review.md`: the notes from the Sprint Review (a 10-minute demonstration, as a video or in person) and the feedback from the tutor

The stand-ups are assessed individually. Each member writes their own lines in this format:

```markdown
## Stand-up, <date>

### <name>
- Done since the last stand-up:
- Next:
- Blockers:
```
