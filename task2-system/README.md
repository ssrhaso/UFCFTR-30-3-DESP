# Task 2: system development (60%)

Task 2 runs over three sprints in TB2. It is due in the last week of TB2 (week 37, w/c 26 Apr 2027). The group builds a web application as an enterprise system with Django, Django REST Framework, Docker and a relational database (for example, PostgreSQL or MySQL). The module team supplies the test cases. The operational BPMN models from Task 1 become microservices in this system.

The Django project, the Dockerfiles and the Docker Compose file will be in this folder. The work starts in TB2.
