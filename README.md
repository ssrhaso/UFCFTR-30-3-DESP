# UFCFTR-30-3 Distributed and Enterprise Software Development

This repository holds the group project for the Distributed and Enterprise Software Development module (UFCFTR-30-3) at UWE Bristol, 2026-27.

## Assessment tasks

| Task | Weight | Content |
|---|---|---|
| Task 1 | 40% | BPMN modelling: a strategic BPMN model, an executable operational BPMN model (Camunda) and an i* socio-technical model |
| Task 2 | 60% | System development with Django, Django REST Framework, Docker and a relational database |

The team works in 3-week Scrum sprints. The operational BPMN models from Task 1 become microservices in the Task 2 system.
