# Task 1: BPMN modelling (40%)

Task 1 runs over three sprints in TB1. It is due in the last week of TB1 (week 18, w/c 14 Dec 2026). The group builds three linked models and a critical evaluation, and demonstrates them in class.

| Folder | Content | Files |
|---|---|---|
| [strategic/](strategic/) | Strategic-level BPMN model of the enterprise system architecture | `.bpmn`, with a `.png` or `.svg` export |
| [operational/](operational/) | Operational-level BPMN models of the components and services. They must execute in Camunda 8, and they become microservices in Task 2 | `.bpmn`, `.form`, `.dmn` |
| [istar/](istar/) | i* socio-technical model of the user goals and dependencies | The source file of the modelling tool, with a `.png` or `.svg` export |
| [evaluation/](evaluation/) | Critical evaluation of the legal, ethical, social and professional implications of the processes in the models | `.md` |

The Camunda Web Modeler stores the models in the module's Camunda organisation. After each change, download the model and commit it here. The repository then records the history of the models and the contribution of each member.
