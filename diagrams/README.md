# Diagrams

This folder holds the diagrams that are not BPMN or i* models, for example architecture, component, service, deployment and data (ER) diagrams.

- Keep the source file (for example, `.drawio`, `.puml` or `.mmd`) and an export (`.png` or `.svg`) with the same name.
- Use lowercase names with hyphens, for example `system-architecture.drawio` and `system-architecture.svg`.
